# Mealy & Moore Machine Lab

An interactive Automata Theory workbench and simulator for designing, converting, and testing **Mealy Machines** and **Moore Machines**.

Built with **React**, **TypeScript**, **Vite**, and **@xyflow/react** (React Flow).

## 🚀 Quick Start

### 1. Install dependencies
```bash
npm install
```

### 2. Run development server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Build for production
```bash
npm run build
```

## ✨ Features at a Glance

- **Interactive State Diagrams:** Drag-and-drop nodes, curved bidirectional transitions, self-loops, and start state indicators.
- **Synchronized Transition Tables:** Edit transitions visually on the diagram or formally via tabular inputs.
- **Step-by-Step Simulator:** Watch transitions execute in real time with synchronized graph edge/node highlighting.
- **Formal Model Conversion:** Algorithmic conversion between Mealy and Moore machines with automated equivalence verification.
- **Theory & Guides:** Detailed automata theory, formal 6-tuple definitions, and practical application notes.
